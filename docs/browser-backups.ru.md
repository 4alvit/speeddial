Скрипты сохраняют **панель Speed Dial**: порядок ссылок, названия, полные байты изображений, строки, столбцы, способ открытия и язык. Они не копируют историю браузера, пароли, расширения или посторонние закладки. Используется переносимый JSON-формат приложения `speedial-local-backup`, а не внутренние базы Chrome или Firefox.

Они работают с локальной браузерной версией на [speeddial.alvit.here.now](https://speeddial.alvit.here.now/). Они не заменяют [серверные резервные копии](../wiki/Operations.md#backup-and-restore) для Node.js, Docker или k3s. Старый JSON-экспорт сервера не принимается как полная браузерная копия; для переноса такой панели требуется [сбор и преобразование изображений](browser-migration.md).

Если панель ещё находится по прежнему адресу `speedial.alvit.here.now`, сначала экспортируйте её именно оттуда: теперь скрипты открывают `speeddial.alvit.here.now`. Используйте `--no-open` с уже открытой старой вкладкой или явно архивируйте сохранённый экспорт. Старые файлы `speedial-local-backup` и имена загрузок `speedial-backup-*.json` поддерживаются. См. [пояснения о смене адреса](local-speedial.md#corrected-address-and-existing-backups).

## Требования и поддержка браузеров

Запускайте Node.js 24+ из этой рабочей копии Git. Устанавливать дополнительные пакеты не требуется. На macOS средство запуска распознаёт Chrome, Firefox, Safari, Edge, Brave, Arc, Opera, Vivaldi, Chromium, Orion, Zen, LibreWolf и Waterfox в `/Applications`, `~/Applications` или `/System/Applications`. Это поддержка запуска, а не утверждение о проверке каждого браузера. Автоматические проверки приложения используют Chromium, Firefox и WebKit.

```sh
npm run backup:browser -- --list-browsers
```

Для другого браузера macOS используйте `--app /absolute/path/Browser.app`. Для уже открытого браузера, встроенного браузера Codex, Windows или Linux используйте `--no-open` и откройте сайт самостоятельно. Отладочный порт, расширение, разрешение Accessibility и прямой доступ к файлам профиля не нужны.

```sh
npm run backup:browser -- --no-open
npm run restore:browser -- backups/YOUR-BACKUP.json --no-open
npm run restore:browser -- backups/YOUR-BACKUP.json --app "/Applications/Brave Browser.app"
```

Адрес запуска закреплён за основным доменом. Панель, сохранённую на другом origin, нужно экспортировать именно оттуда; используйте там `--no-open` и самостоятельно проверяйте адрес назначения. Хранилище браузера не переносится при перенаправлении или смене имени хоста.

**Скрипты интерактивные.** Они открывают приложение и управляют локальными файлами, но экспорт, выбор файла импорта и подтверждение замены выполняете вы. Приложение может иметь несколько профилей: выберите нужный и используйте [speeddial.alvit.here.now](https://speeddial.alvit.here.now/). Пустая панель в новом профиле ожидаема. Скрипт не может подтвердить, какой профиль создал загруженный файл.

## Резервное копирование из Chrome

```sh
npm run backup:browser -- --browser chrome
```

1. Выберите существующий профиль Chrome, раскройте стрелку справа сверху и нажмите **Export backup**.
2. Сохраните файл с предложенным именем `speedial-backup-YYYY-MM-DD.json` в `~/Downloads`. Суффиксы совпадающих имён, например ` (1)`, поддерживаются.
3. Скрипт ждёт новый завершённый экспорт, проверяет его, копирует в `backups/`, перечитывает копию и выводит путь, количества элементов и SHA-256. Он никогда не подставляет старый экспорт. Несколько одновременных экспортов вызывают ошибку, а не выбор наугад.

Если браузер сохраняет файлы в другом месте, используйте `--downloads /absolute/local/folder` и выберите ту же папку в браузере. Выбирайте локальные папки вне каталогов облачной синхронизации. По умолчанию ожидание длится десять минут; `--timeout 1200` увеличивает его до двадцати. В диалоге браузера **Save As** может потребоваться подтверждение, прежде чем файл появится. Для переименованного или уже скачанного экспорта:

```sh
npm run backup:browser -- --file /absolute/local/export.json
```

Режим явного файла архивирует именно этот файл; он **не** получает текущие данные браузера и не подтверждает их актуальность. Оригиналы загрузок сохраняются. Для экспортов, полученных наблюдателем, на POSIX задаётся режим `0600`; явно указанные входные файлы не меняются.

## Восстановление в другом браузере

Замените `YOUR-BACKUP.json` напечатанным именем резервной копии:

```sh
npm run restore:browser -- backups/YOUR-BACKUP.json --browser firefox
npm run restore:browser -- backups/YOUR-BACKUP.json --browser chrome
npm run restore:browser -- backups/YOUR-BACKUP.json --browser safari
```

Команда восстановления требует интерактивный терминал и ведёт работу с одним браузером/профилем за раз:

1. Она проверяет источник и сохраняет отдельную копию `restore-source`. В целевом профиле экспортируйте текущую панель, даже пустую. Скрипт сохранит её как `before-restore`, чтобы панель можно было восстановить.
2. Подтвердите в терминале, что экспорт получен из правильного целевого профиля, введя `RESTORE`.
3. В том же браузере нажмите **Import backup**, выберите напечатанный файл `restore-source`, проверьте сводку и нажмите **Replace this board**. На macOS в диалоге выбора файла нажмите **⌘⇧G** и вставьте абсолютный путь.
4. Перезагрузите Speed Dial, проверьте отображение изображений и экспортируйте ещё раз. Скрипт архивирует этот экспорт `after-restore` и сравнивает с источником порядок ссылок, названия, байты изображений, сетку, способ открытия и язык. Новые внутренние идентификаторы и временные метки игнорируются. Старые копии без языка оставляют язык назначения прежним.

Успех сообщается только после совпадения содержимого. Несовпадение или таймаут **не** означают проверенное восстановление. Все копии сохраняются; автоматического отката нет. Для отката повторите команду с сохранённым файлом `before-restore`. Совпадение экспортов доказывает равенство содержимого; профиль, origin и отображение изображений всё равно нужно проверить.

Для последующего возврата в Chrome используйте ту же команду восстановления с `--browser chrome` и нужным сохранённым JSON-файлом. Формат не зависит от браузера-источника. Каждое восстановление заменяет одну целевую панель, а не объединяет ссылки; сохраните автоматически созданную копию назначения, если могут понадобиться обе версии.

Пока команда ждёт, не экспортируйте из другой вкладки или профиля. Для разных браузеров запускайте отдельные команды. Это разовый перенос: последующие изменения не синхронизируются.

## Только локальное хранение и проверка

Весь файловый вывод скриптов поступает в фиксированный каталог `backups/` этой рабочей копии. Команда проверяет, что Git игнорирует его и что в нём нет отслеживаемых файлов. Каталог вывода в виде символической ссылки отклоняется. Каждая копия получает уникальное имя, записывается без перезаписи другого файла, перечитывается и сопровождается `.receipt.json` с количествами и хешами, но без названий и URL. Некорректные входные данные не создают копию. CLI использует общие с приложением проверки схемы, base64 и заголовков растров; целевое приложение дополнительно декодирует изображения перед атомарным импортом.

Для восстановления используйте файл панели `.json`, а не сопутствующий `.receipt.json`. Квитанция содержит метаданные проверки и не может восстановить панель. Скрипты не удаляют старые копии или оригиналы загрузок автоматически; сохраняйте нужные копии и управляйте их хранением локально.

На macOS/Linux каталог имеет режим `0700`, файлы — `0600`. На Windows ограничьте доступ файловыми ACL учётной записи; режимы POSIX не гарантируют ACL. JSON-копии хранятся открытым текстом. В скриптах нет кода загрузки или синхронизации. Папка исключена из Git, контекста сборки Docker и списка разрешённых файлов публичного интерфейса. `.gitignore` не мешает принудительному добавлению в Git, ручной передаче, резервному копированию ОС или отдельно настроенному клиенту синхронизации. Для исключительно локального хранения размещайте рабочую копию и папку загрузок вне синхронизируемых каталогов.

Данные панелей не встроены в скрипты, тесты, документацию или публичный сайт. См. [ограничения браузерного хранения](local-speedial.md#what-is-private-and-what-is-not) и [приёмку миграции](browser-migration.md).
