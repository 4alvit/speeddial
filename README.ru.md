## Публичная локальная версия: Speedial

[Открыть Speedial](https://speedial.alvit.here.now/) — публичное приложение с данными в браузере. Это основной адрес: сохраните его в закладках и используйте для своей доски. [Хранение, защита и перенос данных](docs/local-speedial.md).

Каждый посетитель начинает с пустой доски. Ссылки, настройки и байты картинок остаются в этом профиле браузера; тот же адрес сайта или скопированный ID доски на другом компьютере их не открывает. Общего API доски, облачной синхронизации и автоматических скриншотов сайтов нет. Сохранены пять языков и управление плитками.

**Экспорт копии** и **Импорт копии** позволяют явно перенести всю доску, включая изображения и язык. После просмотра и подтверждения импорт заменяет доску назначения. У разных доменов, браузеров и профилей отдельные хранилища, даже если код приложения одинаков. JSON-копия не зашифрована: храните её приватно. Очистка браузера может удалить локальную доску.

Сборка: `npm run build:local`; проверка: `npm run test:local`. Публиковать можно только разрешённые файлы из `dist/local`. Серверная версия, описанная ниже, остаётся отдельной.

### Локальный бэкап и перенос между браузерами

С Node.js 24+ из каталога репозитория:

```sh
npm run backup:browser -- --browser chrome
npm run restore:browser -- backups/YOUR-BACKUP.json --browser firefox
```

Замените `YOUR-BACKUP.json` именем сохранённой копии. Скрипты помогают экспортировать и импортировать полную панель с картинками и настройками. Экспорт и подтверждение замены выполняются в нужном профиле браузера. Копии остаются в исключённой из Git папке `backups/`; перед заменой сохраняется прежняя панель, а после проверяется новый экспорт. На macOS доступен запуск Chrome, Firefox и других установленных браузеров; `--no-open` подходит для уже открытого браузера, Windows и Linux. Это не синхронизация и не чтение внутренних баз профиля. [Полная инструкция](docs/browser-backups.ru.md).

## Серверная версия

Общая страница закладок на собственном сервере: компактные плитки со скриншотами, редактирование, обмен ровно двух позиций и сохраняемые настройки. Интерфейс доступен на английском, русском, немецком, французском и испанском.

Сервер читает секреты из внешних файлов и хранит данные вне образа приложения. Публичный `speeddial` содержит исходный код и общие примеры развёртывания. Закрытый репозиторий эксплуатации хранит историю и материалы восстановления, используя закреплённую ревизию публичного кода без его дублирования.

## Возможности

Шапка по умолчанию свёрнута; стрелка справа открывает настройки, экспорт и добавление сайта. Подписей под плитками нет. При перетаскивании превью следует за указателем, меняются местами только исходная и целевая плитки. Есть сенсорная ручка и управление с клавиатуры.

Можно выбрать 1–12 строк и столбцов; по умолчанию 4 × 5. Остальные закладки остаются на следующих страницах. Ссылки открываются в том же окне, если не выбран новый контекст. Язык хранится в этом браузере, а размеры сетки и способ открытия ссылок общие для доски.

Новые адреса получают скриншот автоматически. Допускаются PNG, JPEG, WebP и GIF до 5 МиБ. Серверный браузер не получает ваши cookies входа; для приватных сайтов можно загрузить изображение. Новая база по умолчанию пустая.

## Доступ и запуск

Нужны Node.js 24+, установленный Chromium и два обязательных внешних файла:

- `ACCESS_TOKEN_FILE`: случайный URL-safe токен длиной не менее 32 символов после удаления пробелов по краям.
- `SESSION_KEY_FILE`: ключ подписи из не менее 32 сырых байтов.

Форма входа — `https://bookmarks.example.test/?access=<token>`. Это пример, а не рабочий адрес. Токен нужен при каждом открытии страницы; выданная cookie разрешает чтение и редактирование. Отдельного пароля редактора нет. Смена токена, ключа или `AUTH_EPOCH` отзывает прежние cookies после перезапуска.

Не помещайте секреты, полные ссылки доступа, базу и личные изображения в Git или образ. Инструкция безопасного создания локальных файлов находится в [английском README](README.md#local-development).

```sh
npm ci
npm run check
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

`DATA_DIR` хранит SQLite, `images/` и перенесённые `legacy-images/`. Необязательный `INITIAL_STATE_FILE` заполняет только новую базу из внешнего файла. Существующая база не пересоздаётся.

## Эксплуатация и публикация

[Wiki](wiki/Home.md), [API](wiki/API.md), [конфигурация](wiki/Configuration.md), [переключение и восстановление](deploy/README.md), [безопасность](SECURITY.md), [процесс на русском](wiki/Process-and-Results.ru.md). Подробные технические инструкции ведутся на английском.

**Серверный** JSON-экспорт не содержит байты изображений и не является полной резервной копией. Для восстановления нужны согласованные данные и внешние секреты в защищённом хранилище вне узла. Бэкап браузерной версии имеет другой формат и содержит изображения. Перед миграцией проверьте восстановление на изолированной копии данных.

Запуск через [Docker](README.md#docker) и [k3s / Kubernetes](README.md#k3s--kubernetes) сохранён. Docker-пример использует постоянную папку данных и секреты вне образа; манифесты k3s требуют собственного overlay с образом, хранилищем и маршрутом. Публикация локальной версии не меняет серверный деплоймент. Для страницы самой организации есть [инструкция и пример README](docs/organization-profile.md).

Этот публичный репозиторий имеет новую историю исходников и синтетические примеры. Прежняя приватная история остаётся в закрытом репозитории эксплуатации и не переносится сюда. Бэкапы, секреты и личные данные исключены из Git. Код доступен для просмотра, но сохраняет статус `UNLICENSED`: открытая лицензия на распространение не предоставлена.
